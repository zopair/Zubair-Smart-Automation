# موصل الذكاء الاصطناعي الاختياري

## التصميم

- المتصفح يرسل طلباً إلى المسار المحلي /api/generate فقط.
- خادم المعاينة يحتفظ بمفتاح المزود في متغير بيئة على الخادم.
- لا تُرسل مفاتيح API إلى JavaScript أو localStorage أو ملفات HTML المستقلة.
- المسار الحالي يسمح بمهمتي shorts-script وtool-spec فقط؛ الثانية تنتج مواصفات لا شيفرة. لا يقبل الخادم عنوان URL أو اسم أداة من المستخدم.
- الطلبات محدودة الحجم، ومحمية بفحص Origin ومعدل طلبات لكل عنوان IP، مع مهلة للاتصال.
- مخرجات المزود تُعرض كنص عادي عبر textContent ولا تُنفذ كـ HTML.

## الإعداد المحلي

اضبط المتغيرات في بيئة تشغيل Node قبل تشغيل المعاينة:

- AI_API_KEY: مفتاح المزود، ويظل على الخادم فقط.
- AI_MODEL: اسم النموذج الذي يدعمه المزود.
- AI_API_URL: اختياري؛ افتراضياً نقطة Chat Completions لدى OpenAI.
- AI_API_STYLE: اختياري؛ chat-completions افتراضياً أو responses عند استخدام Responses API.
- PORT: اختياري؛ منفذ خادم المعاينة، الافتراضي 4173.

بعد بناء التطبيق شغّل خادم المعاينة في نفس البيئة التي تحتوي على المتغيرات. يعرض /api/health حالة الاتصال فقط دون كشف المفتاح. لا يفعّل GitHub Pages هذه الواجهة الخلفية؛ الاستضافة الثابتة ستخفي زر التوليد الآلي ما لم تُربط بخدمة API آمنة على نفس الأصل أو عبر إعداد CORS ومصادقة مصمم بعناية.

## حدود الإصدار

- لا يوجد مفتاح أو مزود افتراضي مضمّن في المستودع.
- لا توجد إدارة مستخدمين أو حصص تكلفة على مستوى الحساب حتى الآن.
- حد المعدل الحالي داخل ذاكرة عملية Node الواحدة، ويعاد ضبطه عند إعادة التشغيل.
- لا تستخدم هذا الخادم كواجهة عامة مفتوحة دون إضافة مصادقة، وحصص إنفاق، ومراقبة إساءة الاستخدام، وتخزين أسرار مناسب، وطبقة reverse proxy.
- المخرجات مسودات تحتاج مراجعة بشرية؛ تعليمات النموذج لا تضمن خلوها من الهلوسة.
- لا ترسل بيانات شخصية أو أسراراً أو معلومات عملاء إلى المزود إلا بعد اعتماد سياسة البيانات والاحتفاظ المناسبة.

## توافق المزود

يستخدم التنفيذ الافتراضي تنسيق Chat Completions المتوافق مع عدة مزودين. يمكن اختيار AI_API_STYLE=responses لاستخدام Responses API مع نقطة /v1/responses، أو تحديد AI_API_URL يدوياً. توصي وثائق OpenAI بتجربة Responses للمشروعات الجديدة؛ أبقينا Chat Completions افتراضياً للتوافق مع المزودين المتوافقين.
