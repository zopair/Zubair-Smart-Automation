# النشر على GitHub Pages

## تجهيز المستودع

1. افتح Settings في مستودع Zubair-Smart-Automation.
2. افتح Pages.
3. في Build and deployment اختر GitHub Actions كمصدر.
4. افتح تبويب Actions.
5. اختر Deploy to GitHub Pages ثم Run workflow على الفرع main.

ملف النشر يبني المشروع ويشغّل فحوص الصياغة والاختبارات قبل رفع مجلد dist. النشر يدوي عمداً حتى لا يتحول كل commit إلى إصدار عام دون مراجعة.

## عنوان الموقع المتوقع

https://zopair.github.io/Zubair-Smart-Automation/

استخدم المسارات النسبية في الواجهة حتى تعمل تحت مسار المستودع، وملف .nojekyll لمنع معالجة Jekyll للملفات.

## حدود الاستضافة الثابتة

- GitHub Pages يستضيف الواجهة الثابتة فقط.
- لا يعمل scripts/preview.mjs أو scripts/ai-api.mjs على Pages.
- ستظل أدوات المتصفح المحلية والمتجر ومخطط الفيديو والكتالوج تعمل، لكن أزرار التوليد بالذكاء الاصطناعي ستظل مخفية حتى يتوفر API خلفي آمن.
- لا تضع AI_API_KEY أو أي سر في GitHub Pages أو متغيرات بناء الواجهة الأمامية.
- لتفعيل الذكاء الاصطناعي في الإنتاج، استضف scripts/ai-api.mjs أو خدمة API مكافئة على خادم منفصل، ثم صمم مصادقة وحصص استخدام وCORS محدوداً قبل ربطه بالواجهة.

## ملاحظة الترخيص

المشروع لا يزال بلا LICENSE معتمد. المستودع عام، لكن لا ينبغي افتراض أن ذلك يمنح إذناً بإعادة الاستخدام. حسم الترخيص مطلوب قبل اعتبار النشر العام إصداراً قابلاً لإعادة التوزيع.
