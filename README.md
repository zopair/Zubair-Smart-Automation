# Zubair Smart Automation

منصة عربية لتوليد أدوات أتمتة وأعمال صغيرة تعمل محلياً في المتصفح، مع أولوية للخصوصية.

## الترخيص
المستودع عام، لكن لم يُعتمد بعد ملف ترخيص للمشروع نفسه. لا يُفترض أن إتاحة الكود للعرض تعني السماح بإعادة استخدامه أو توزيعه. يُحسم الترخيص قبل أول إصدار عام قابل لإعادة الاستخدام.

## الحالة
MVP تأسيسي: واجهة RTL، تحليل أولي للطلبات، سجل قوالب قابل للتوسع، مدير مهام محلي، ومتجر مصغر لإدارة المنتجات والمخزون والسلة والطلبات عبر واتساب، ومخطط إنتاج للفيديوهات القصيرة بتقسيم زمني وسيناريو ووسوم، وكتالوج مصادر تقنية مع مراجعة أولية للتراخيص، ومركز سير عمل محلي بخطوات مسموح بها وموافقة صريحة وسجل تدقيق.

## التشغيل
يتطلب Node.js 20 أو أحدث:
```bash
npm test
npm run check
npm run build
npm run preview
```
ثم افتح http://127.0.0.1:4173. هذا بناء ثابت متعدد الملفات؛ القوالب المدعومة توفر تصديراً مستقلاً كملفات HTML تعمل دون موارد خارجية.

## الهيكل
- `src/core/request-analyzer.js`: تصنيف وصف المستخدم.
- `src/core/tool-registry.js`: سجل قوالب الأدوات.
- `src/tools/task-manager.js`: إدارة مهام محلية.
- `src/tools/task-manager-export.js`: توليد نسخة HTML مستقلة من قالب المهام.
- `src/core/storefront-store.js`: منطق المنتجات والمخزون والسلة والطلبات والتحقق من بياناتها.
- `src/tools/mini-store.js`: واجهة إدارة المتجر وسجل الطلبات وتجهيز واتساب.
- `src/tools/mini-store-export.js`: توليد متجر مستقل دون اعتماديات خارجية.
- `src/core/shorts-planner.js`: بناء مخطط فيديو منظم دون اختلاق حقائق أو أرقام.
- `src/tools/shorts-planner.js`: واجهة تخطيط المحتوى القصير.
- `src/tools/shorts-planner-export.js`: نسخة مستقلة من مخطط الفيديو.
- `src/core/source-catalog.js`: بيانات المصادر التقنية وحدود التراخيص.
- `src/tools/source-catalog.js`: البحث والتصفية في الكتالوج.
- `src/tools/source-catalog-export.js`: تصدير الكتالوج كملف HTML مستقل.
- `docs/source-audit.md`: نتائج مراجعة خمسة مصادر وحدود التدقيق.\n- `src/core/agent-workflow.js`: محرك خطوات مسموح بها مع موافقة صريحة وسجل أحداث محلي.\n- `src/tools/agent-workflow.js`: واجهة إعداد واعتماد وتنفيذ سير العمل.\n- `docs/agent-security.md`: حدود أمان الوكلاء وما يلزم قبل ربط موصلات خارجية.
- `src/main.js`: ربط الواجهة.
- `tests/`: اختبارات.
- `scripts/`: بناء ومعاينة ثابتة.

## تقييم المصادر المفتوحة
راجع [سياسة اختيار المصادر](docs/source-selection.md) و[تدقيق المستودعات الأولي](docs/source-audit.md). لا تُضاف مكتبة خارجية قبل فحص الترخيص والحجم والصيانة وسطح الهجوم.

## مبادئ الأمان
- لا مفاتيح API أو أسرار داخل كود المتصفح.
- لا تنفيذ لنص المستخدم ككود.
- تخزين محلي مع توضيح ذلك للمستخدم.
- أي تكامل يتطلب أسراراً يمر عبر وسيط آمن اختياري.
- عزل معاينات الأكواد المستقبلية.

## خارطة الطريق
1. تأسيس الجودة وCI — مكتمل مبدئياً.
2. تدفق التوليد الآمن — قوالب المهام والمتجر ومخطط الفيديو والكتالوج متاحة.
3. استكمال تدقيق قائمة المستودعات الـ150 وتوسيع كتالوج المصادر.
4. محرك سير عمل للوكلاء بصلاحيات وموافقات وسجل تدقيق.
5. ربط مزود LLM وموصلات خارجية عبر وسيط آمن للأسرار، مع صلاحيات دقيقة وموافقات لكل عملية حساسة.\n6. النشر العام بعد استكمال التحقق الأمني واختبارات التشغيل.
لا تعتبر أي ميزة مكتملة قبل اختبارها في المتصفح.
